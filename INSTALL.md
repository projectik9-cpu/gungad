# 📦 Инструкция по установке GunGad Casino Bot

## Требования

Перед установкой убедитесь, что у вас установлены:

- **Node.js** версии 18.0.0 или выше
- **PostgreSQL** версии 14 или выше (опционально)
- **Redis** версии 6.0 или выше (опционально)

## Шаг 1: Клонирование репозитория

```bash
git clone <repository-url>
cd gungad-casino-bot
```

## Шаг 2: Установка зависимостей

```bash
npm install
```

## Шаг 3: Настройка переменных окружения

Файл `.env` уже создан с вашим токеном бота. Проверьте и при необходимости измените настройки:

```env
BOT_TOKEN=8749759791:AAHNBAQ5vcGOufvaF9baYd_mF_E-AgigZGE
```

### Настройка базы данных (опционально)

Если вы хотите использовать PostgreSQL:

1. Создайте базу данных:
```bash
psql -U postgres
CREATE DATABASE gungad_casino;
\q
```

2. Обновите настройки в `.env`:
```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=gungad_casino
DB_USER=postgres
DB_PASSWORD=ваш_пароль
```

3. Запустите миграцию:
```bash
npm run db:migrate
```

### Без базы данных

Бот может работать и без PostgreSQL, но некоторые функции будут ограничены. База данных необходима для:
- Сохранения профилей пользователей
- Истории игр и транзакций
- Реферальной системы
- Статистики

## Шаг 4: Запуск бота

### Режим разработки (с автоперезагрузкой):

```bash
npm run dev
```

### Режим продакшн:

```bash
npm start
```

## Шаг 5: Проверка работы

1. Откройте Telegram и найдите вашего бота
2. Отправьте команду `/start`
3. Вы должны увидеть приветственное сообщение с кнопкой для открытия веб-приложения

## Веб-приложение

Веб-сервер запускается автоматически вместе с ботом на порту 3000.

Для доступа к веб-интерфейсу:
- Локально: http://localhost:3000
- Telegram Web App: будет использовать URL из переменной `WEB_APP_URL`

## Основные команды

```bash
npm start           # Запуск бота
npm run dev         # Запуск в режиме разработки
npm run db:migrate  # Миграция базы данных
npm run db:seed     # Заполнение тестовыми данными
npm test            # Запуск тестов (когда будут добавлены)
```

## Возможные проблемы и решения

### Ошибка: "Cannot find module"

Убедитесь, что все зависимости установлены:
```bash
npm install
```

### Ошибка подключения к базе данных

Проверьте:
1. PostgreSQL запущен
2. База данных создана
3. Настройки в `.env` корректны
4. Пользователь имеет права доступа

### Бот не отвечает

Проверьте:
1. Токен бота корректен
2. Бот запущен (посмотрите логи)
3. Нет ошибок в консоли

### Веб-приложение не открывается

Проверьте:
1. Порт 3000 не занят другим приложением
2. URL веб-приложения настроен в `.env`
3. Веб-сервер запустился (смотрите логи)

## Логи

Логи сохраняются в директории `logs/`:
- `bot.log` - все логи
- `error.log` - только ошибки

Просмотр логов в реальном времени:
```bash
tail -f logs/bot.log
```

## Следующие шаги

1. **Добавить ваше веб-приложение**: Замените содержимое в `src/web/server.js` на ваш фронтенд
2. **Настроить платёжную систему**: Добавьте провайдера платежей в `.env`
3. **Добавить игры**: Реализуйте логику игр в `src/services/gameService.js`
4. **Настроить админ-панель**: Создайте обработчики для администраторов
5. **Оптимизировать**: Добавьте Redis для кэширования

## Поддержка

Если возникли проблемы:
1. Проверьте логи в директории `logs/`
2. Убедитесь, что все зависимости установлены
3. Проверьте настройки в `.env`

## Безопасность

⚠️ **Важно:**
- Никогда не публикуйте файл `.env` в Git
- Измените `JWT_SECRET` и `ENCRYPTION_KEY` в продакшене
- Используйте сильные пароли для базы данных
- Регулярно обновляйте зависимости: `npm update`
