КРИТИЧЕСКИ ВАЖНО — VITE_API_URL
---------------------------------
WebApp на Vercel шлёт ставки / auth / heartbeat на бот-сервер (Express /api).
Бот-сервер должен быть публично доступен (не localhost).

Если бот запущен на VPS:
  vercel env add VITE_API_URL production
  → введи: https://твой-домен-или-ip:3000

Если используешь ngrok для теста:
  ngrok http 3000
  vercel env add VITE_API_URL production
  → введи: https://xxx.ngrok.io

После добавления — redeploy:
  cd gungad-casino && npx vercel --prod --yes
