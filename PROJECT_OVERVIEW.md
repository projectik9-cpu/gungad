✅ **Users** - пользователи

✅ **Transactions** - транзакции

✅ **GameSessions** - игровые сессии

  - Сумма ставки

  - Детальные данные игры

#### Связи:
✅ User → Transactions (один ко многим)
✅ User → GameSessions (один ко многим)
✅ User → User (реферальная система)
✅ GameSession → Transactions (один ко многим)

## 🎨 Кастомизация

### Изменение настроек игры:
Отредактируйте `src/config/config.js`:
```javascript
game: {
  startingBalance: 1000,        // Стартовый баланс
  dailyBonusAmount: 100,        // Ежедневный бонус
  referralBonus: 500,           // Бонус новому пользователю
  referralReward: 250,          // Награда рефереру
  minBet: 10,                   // Минимальная ставка
  maxBet: 10000,                // Максимальная ставка
}
```

### Изменение сообщений:
Отредактируйте `src/bot/messages.js`

### Изменение клавиатур:
Отредактируйте `src/bot/keyboards.js`
