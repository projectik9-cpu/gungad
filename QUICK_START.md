# 🚀 Быстрый старт GunGad Casino Bot

## Минимальная установка (без базы данных)

Если вы хотите просто запустить бота без настройки PostgreSQL:

### 1. Установите зависимости

```bash
npm install
```

### 2. Запустите бота

```bash
npm start
```

Бот запустится и будет работать без базы данных. Это означает, что:
- ✅ Бот будет отвечать на команды
- ✅ Веб-приложение будет доступно
- ❌ Данные пользователей не будут сохраняться
- ❌ История игр не будет сохраняться

## Полная установка (с базой данных)

### 1. Установите PostgreSQL

#### Windows
Скачайте и установите с официального сайта: https://www.postgresql.org/download/windows/

#### Linux (Ubuntu/Debian)
```bash
sudo apt update
sudo apt install postgresql postgresql-contrib
```

#### macOS
```bash
brew install postgresql
brew services start postgresql
```

### 2. Создайте базу данных

```bash
# Подключитесь к PostgreSQL
psql -U postgres

# Создайте базу данных
CREATE DATABASE gungad_casino;

# Выйдите
\q
```

### 3. Настройте .env

Откройте файл `.env` и обновите настройки базы данных:

```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=gungad_casino
DB_USER=postgres
DB_PASSWORD=ваш_пароль_от_postgres
```

### 4. Запустите миграцию

```bash
npm run db:migrate
```

### 5. Запустите бота

```bash
npm start
```

## Помощь

### Не запускается бот?

1. Проверьте, что Node.js установлен: `node --version`
2. Проверьте, что зависимости установлены: `npm install`
3. Проверьте токен бота в `.env`
4. Посмотрите логи в консоли

### Не работает база данных?

1. Проверьте, что PostgreSQL запущен
2. Проверьте настройки в `.env`
3. Попробуйте запустить без БД (см. "Минимальная установка")

### Другие проблемы?

Откройте файл `logs/error.log` и посмотрите на ошибки.
