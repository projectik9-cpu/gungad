## 📖 О проекте

**GunGad Casino Bot** - это полноценное решение для создания казино в Telegram с интеграцией веб-приложения. Проект включает в себя все необходимое для запуска: от Telegram бота до системы управления балансами и играми.

### ✨ Ключевые особенности

🤖 **Telegram Bot** - Полностью функциональный бот с командами и inline-клавиатурами
🌐 **Web App** - Интеграция с Telegram Web App для полноценного казино
💰 **Балансы** - Система виртуальной валюты с транзакциями
🎁 **Бонусы** - Ежедневные бонусы и реферальная программа
🎮 **Игры** - Готовая архитектура для добавления мини-игр
📊 **Статистика** - Детальная статистика по играм и пользователям
🔒 **Безопасность** - Валидация данных и защита от атак
📝 **Логирование** - Профессиональная система логов

## 🎨 Настройки

### Изменить игровые параметры

Отредактируйте `src/config/config.js`:

```javascript
game: {
  startingBalance: 1000,      // Стартовый баланс
  dailyBonusAmount: 100,      // Ежедневный бонус
  dailyBonusInterval: 24h,    // Интервал бонуса
  referralBonus: 500,         // Бонус новому пользователю
  referralReward: 250,        // Награда рефереру
  minBet: 10,                 // Минимальная ставка
  maxBet: 10000,              // Максимальная ставка
}
```

### Изменить сообщения

Отредактируйте `src/bot/messages.js`

### Изменить клавиатуры

Отредактируйте `src/bot/keyboards.js`

## 🆘 Решение проблем

### Бот не запускается?

1. Проверьте Node.js: `node --version` (должно быть >= 18)
2. Установите зависимости: `npm install`
3. Проверьте токен бота в `.env`
4. Посмотрите логи: `cat logs/error.log`

### База данных не работает?

1. Проверьте PostgreSQL: `pg_isready`
2. Проверьте настройки в `.env`
3. Попробуйте запустить БЕЗ базы данных (для теста)

### Порт 3000 занят?

```bash
# Linux/Mac
lsof -ti :3000 | xargs kill -9

# Windows
netstat -ano | findstr :3000
taskkill /PID <PID> /F
```
